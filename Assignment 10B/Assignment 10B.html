Transforming JSON into a Tidy Data Frame

The Nobel Prize API returns nested JSON data containing information about individual laureates and their awards. To prepare the data for analysis, I will extract selected fields, including laureate ID, name, gender, birth date, and birth country. Each row will represent one laureate, making it easier to explore their characteristics and connect their information to Nobel Prize records later in the analysis.

# Helper function to safely extract nested JSON values
get_value <- function(x, path) {
  for (field in path) {
    if (is.null(x) || is.null(x[[field]])) {
      return(NA_character_)
    }
    x <- x[[field]]
  }
  as.character(x)
}

# Convert the JSON records into a tidy data frame
laureates_sample <- purrr::map_dfr(
  nobel_json$laureates,
  function(person) {
    tibble(
      laureate_id = get_value(person, c("id")),
      name = get_value(person, c("knownName", "en")),
      gender = get_value(person, c("gender")),
      birth_date = get_value(person, c("birth", "date")),
      birth_country = get_value(
        person, c("birth", "place", "countryNow", "en")
      )
    )
  }
)

Retrieving the Complete Dataset

After successfully transforming the sample JSON data, I will retrieve the complete Nobel laureate dataset. Since the API supports pagination, I will use the limit and offset parameters to retrieve records in batches. This approach ensures that all available laureates are included in the analysis rather than relying on a limited sample.

# Number of laureates requested per API call
page_size <- 100

# Create an empty list to store each batch
all_pages <- list()

# Begin with the first record
offset <- 0

repeat {
  
  # Request a batch of laureates
  response_page <- request(nobel_url) |>
    req_url_query(limit = page_size, offset = offset) |>
    req_perform()
  
  # Convert JSON response into an R list
  page_data <- resp_body_json(
    response_page,
    simplifyVector = FALSE
  )
  
  # Extract laureate records
  records <- page_data$laureates
  
  # Stop if no more records are returned
  if (length(records) == 0) break
  
  # Store the current batch
  all_pages[[length(all_pages) + 1]] <- records
  
  # Stop after the final partial batch
  if (length(records) < page_size) break
  
  # Move to the next batch
  offset <- offset + page_size
}

# Combine all batches into one list
all_laureates <- unlist(all_pages, recursive = FALSE)

# Count the total records retrieved

Extracting Nobel Prize Award Information

The Nobel Prize JSON data contains a nested field called nobelPrizes, which stores information about each laureate’s awards. I will extract the award year, category, and prize portion into a separate tidy data frame. Each row will represent one Nobel Prize received by a laureate. Keeping award information separate from demographic information will allow me to join the datasets and investigate patterns across categories and years.

# Extract Nobel Prize records for each laureate
awards <- purrr::map_dfr(
  all_laureates,
  function(person) {
    
    # Retrieve the laureate's Nobel Prizes
    prizes <- person$nobelPrizes
    
    # Skip records without Nobel Prize information
    if (is.null(prizes) || length(prizes) == 0) {
      return(tibble())
    }
    
    # Create one row for each award
    purrr::map_dfr(
      prizes,
      function(prize) {
        tibble(
          laureate_id = get_value(person, c("id")),
          award_year = as.integer(
            get_value(prize, c("awardYear"))
          ),
          category = get_value(
            prize, c("category", "en")
          ),
          prize_portion = get_value(
            prize, c("portion")
          )
        )
      }
    )
  }
)

Analyzing Gender Representation by Decade

To examine changes in gender representation, I will group Nobel Prize award-recipient records by decade and calculate the percentage associated with women. I will exclude organizations and records without a reported male or female gender to ensure the percentages are based on individual laureates with known gender information. This analysis will help identify whether women’s representation has changed over time.

# Calculate the percentage of female award recipients by decade
gender_by_decade <- nobel_combined |>
  filter(
    gender %in% c("female", "male"),
    award_year >= 1901,
    award_year <= 2026
  ) |>
  mutate(
    decade = floor(award_year / 10) * 10
  ) |>
  group_by(decade) |>
  summarise(
    total_awards = n(),
    female_awards = sum(gender == "female"),
    female_percentage = round(
      female_awards / total_awards * 100, 2
    ),
    .groups = "drop"
  ) |>
  arrange(decade)

Question 3

For this analysis, I will identify laureates who received multiple Nobel Prizes by grouping award records using their unique laureate IDs. I will calculate the number of awards received by each laureate and compare their award categories to determine whether they were recognized in the same field or across different fields.

# Identify laureates who received more than one Nobel Prize
multiple_laureates <- nobel_combined |>
  group_by(laureate_id, name) |>
  summarise(
    total_awards = n(),
    award_years = paste(
      sort(award_year),
      collapse = ", "
    ),
    categories = paste(
      sort(unique(category)),
      collapse = ", "

    .groups = "drop"

  filter(total_awards > 1) |>
  mutate(
    recognition_type = if_else(
      distinct_categories > 1,
      "Different categories",
      "Same category"
    )
  ) |>
  arrange(desc(total_awards), name)

Extracting Institutional Affiliation Data

To investigate international mobility, I will extract institutional affiliation information from the nested Nobel Prize JSON records. The new data frame will contain each laureate’s ID, award year, Nobel Prize category, institution name, and affiliation country. Since some laureates have multiple affiliations, each institution will be represented as a separate observation. Records without affiliation information will be excluded from this table.

# Extract institutional affiliation records
affiliations <- purrr::map_dfr(
  all_laureates,
  function(person) {
    
    purrr::map_dfr(
      person$nobelPrizes,
      function(prize) {
        
        # Retrieve institutional affiliations
        institutions <- prize$affiliations
        
        # Skip awards without affiliation information
        if (is.null(institutions) ||
            length(institutions) == 0) {
          return(tibble())
        }
        
        # Create one row per institution
        purrr::map_dfr(
          institutions,
          function(institution) {
            
            # Prefer present-day country name
            country_now <- get_value(
              institution,
              c("countryNow", "en")
            )
            
            # Use recorded country if present-day is missing
            if (is.na(country_now)) {
              country_now <- get_value(
                institution,
                c("country", "en")
              )
            }
            
            tibble(
              laureate_id = get_value(person, c("id")),
              award_year = as.integer(
                get_value(prize, c("awardYear"))
              ),
              category = get_value(
                prize, c("category", "en")
              ),
              institution = get_value(
                institution, c("name", "en")
              ),
              affiliation_country = country_now
            )
          }
        )
      }
    )
  }
)

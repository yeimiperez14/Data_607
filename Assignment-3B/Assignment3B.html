Approach

For Assignment 3B, I will use a synthetic medication adherence time-series dataset containing daily adherence rates across multiple months for diabetes and hypertension medications. The dataset will include the date, month, medication category, and adherence rate, allowing adherence performance to be followed over time and compared month over month.

Using R and dplyr, I will group the data by medication category and calculate the required year-to-date average and six-day moving average. I will also use the monthly structure of the dataset to observe changes in adherence performance from one month to the next.

Introduction

For this assignment, I use a synthetic medication adherence time-series dataset containing daily adherence rates for diabetes and hypertension medications across multiple months. Using R and dplyr, I calculate a year-to-date average and six-day moving average for each medication category. The monthly structure of the dataset also allows changes in adherence performance to be observed over time.

Calculating the six-day moving average

adherence_data <- adherence_data %>%
  mutate(
    six_day_average = rowMeans(
      cbind(
        adherence_rate,
        lag(adherence_rate, 1),
        lag(adherence_rate, 2),
        lag(adherence_rate, 3),
        lag(adherence_rate, 4),
        lag(adherence_rate, 5)
      ),
      na.rm = FALSE
    )
  )

In this assignment, I used a synthetic medication adherence time-series dataset to calculate window functions for diabetes and hypertension medications. The year-to-date average showed cumulative adherence performance, while the six-day moving average provided a view of shorter-term changes in adherence rates.
